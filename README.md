# BoardGameGeek-Reviews
Este proyecto consiste en el desarrollo de un sistema de recomendación híbrido basado en un dataset de Kaggle del año 2025, centrado en reseñas y valoraciones de juegos de mesa.

A continuación, se presenta toda la documentación correspondiente al proyecto realizado durante el último curso del ciclo Desarrollo de Aplicaciones Multiplataforma (DAM) en Burgos:
